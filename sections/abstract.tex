\begin{abstract}

Deep learning frameworks rely heavily on parameterized operators that compute schedule parameters at runtime to accommodate diverse input shapes and model configurations.
However, this design prevents the underlying compiler from applying aggressive optimizations that depend on static constant information, leading to suboptimal kernel performance.
While specializing kernels by substituting schedule parameters with compile-time constants can recover performance loss, effective constant propagation faces two critical challenges: the \textbf{cross-language semantic gap} between Python-level operator attributes and C++ memory states, and \textbf{early-exit paths} introduced by dynamic shape checks that pollute constant information during data-flow analysis.
We present \mysys, a static analysis framework that enables precise constant propagation across language boundaries for kernel specialization.
\mysys introduces a cross-language context reconstruction method to bridge the Python/C++ semantic gap, and a conditional return-value flow analysis to identify and prune early-exit edges, enabling accurate constant propagation along valid execution paths.
Evaluation results demonstrate that \mysys achieves an average speedup of \textbf{1.06$\times$} (up to \textbf{1.17$\times$}) for Ascend operators and \textbf{3\%} end-to-end inference speedup for LLMs, while reducing binary size by \textbf{96.2\%} for GPU operator libraries through dead code elimination.

\end{abstract}
